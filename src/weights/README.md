# Pretrained HarNet weights

The checkpoint `harnet5_weights.pth` is intentionally not included in this repository because redistribution permission has not been established. Obtain the five-second HarNet checkpoint from the original authors' [ssl-wearables repository](https://github.com/OxWearables/ssl-wearables), following its download instructions and terms, and save it here as `harnet5_weights.pth`.

If you use the checkpoint, please cite:

> Yuan, H. et al. “Self-supervised learning for human activity recognition using 700,000 person-days of wearable data.” *npj Digital Medicine*, 7, 91 (2024).
